# DFR0975-U production Web-UI Power-1 end-to-end acceptance

Date: 2026-10-07
Board: DFR0975-U V1.0 / ESP32-S3 N16R8
Interface: accepted permanently connected direct level shifter
Control surface: production Web UI over the `Landy Heater` access point

## Preconditions

- ESP32 initially powered from USB only.
- Three DS18B20 readings were visible and updating in the production Web UI.
- Heater 12 V was then enabled without an automatic heater start.
- The UI remained connected and reported the heater OFF.
- Board, sensors and level-shifter electronics remained cool.

## User-observed sequence

1. Opened **Configure & start** in the production Web UI.
2. Selected **Power**, level **1 / 9**, duration **30 minutes**.
3. Pressed **Start heater** exactly once.
4. UI reported `STARTING` and the heater physically started.
5. UI reached `RUNNING`; connection remained online and electronics remained
   cool.
6. The heater remained in `RUNNING` for an additional two-minute observation
   interval. Runtime counted down and all three temperatures continued updating
   without a page reload.
7. Pressed **Stop heater** exactly once in the Web UI.
8. UI reported `SHUTTING_DOWN`; 12 V remained connected for the complete
   controlled cooldown.
9. UI finally reported confirmed `OFF`, remained connected and the cooldown
   completed.

## Result

**PASS** for the production Web-UI Power-1 end-to-end path: browser start,
state feedback, stable running observation, live status/temperature updates,
browser stop, controlled shutdown and return to OFF.

This is user-observed target evidence, not a raw protocol capture and not an
endurance test. The earlier bounded active-cycle gate independently proved one
START and one SHUTDOWN at the controller/protocol boundary. This acceptance
does not authorize power levels 2–9, automatic heater starts, external
temperature reporting or either temperature-control mode.
