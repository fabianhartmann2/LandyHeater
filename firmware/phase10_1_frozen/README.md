# Phase 10.1 frozen-module candidate

This directory defines the 44-file DFR0975-U N16R8 source closure for captive
portal and read-only station discovery. It extends the historical Phase-10
closure with the bounded AP DNS adapter and the fair discovery composition.

The ledger binds the current source bytes. Two clean builds were byte-identical
for all 15 compared outputs, and the verified deployment subset is retained in
`artifacts/`. `BUILD_INFO.md` records the exact inputs, hashes, layout and
remaining target gates. Nothing here authorizes or performs a board flash.
